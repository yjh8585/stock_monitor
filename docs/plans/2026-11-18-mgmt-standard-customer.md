## 고르는 규칙 (N5)

1. **주제 묶음**: 이미 받은 목록만으로 263건을 「고객 × 주제」 칸에 배정. 주제 = 품질시스템(BIQS·QSB+·Formel Q·SQ·등급제·Rank-up) / 신규부품 승인(APQP·PPAP·SRV·Run at Rate·ANPQP) / 양산 품질문제·분쟁(SPPS·클레임·GP-12) / 물류(MMOG/LE·라벨·ASN·포장) / CSR·품질매뉴얼 / 구매·계약·행동강령 / 환경·유해물질 / 교육·세미나 / 시스템 사용법.
2. **칸마다 최신 1건**(내용이 둘로 갈리면 2건). 해마다 반복된 교육(Education Day 2013~2017 등)은 마지막 해만.
3. **GM(지시 3)**: 「과거 고객」으로 12장 안 한 절 — 「무엇을 요구받았고 무엇이 사내 표준에 남았나」. GM 주제별 최신 1건(BIQS 2020 · SPPS 2024 · Global GM 2019 묶음 · MMOG/LE 2018 · APQP/PPAP 2014~15 · GM CSR 2025-03)만 읽고 사내에 남은 흔적(협력사 BIQS 인증 · GP-12 · PTR · SPPS)과 잇는다. 2003~2012년 GM 자료는 받지 않는다. 거래 종료 시점은 원문에 없으면 「미확인」.
4. 고르지 않은 문서는 내려받지 않고 부록 C 에 「제목 · 고객 · 연도 · 대신한 최신본」만.
5. 예상(추정 → 1단계에서 실측해 보고): 약 50~60건 · 그룹웨어 요청 약 200회 · 300MB 이내 · 동시 2개 · 401·403·429 즉시 멈춤 · HTML 응답(세션 만료)은 실패 처리(기존 `fetch_list.mjs` 가 이미 함).
