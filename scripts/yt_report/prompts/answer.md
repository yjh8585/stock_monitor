유튜브 영상을 10초 간격으로 뽑은 접촉 시트(한 장 = 6열×4행 = 24칸)를 **직접 눈으로 보고**, 화면에 무엇이 떠 있었는지 정답지를 만든다.
이 정답지로 ①보고서에 넣을 캡처 시각을 고르고 ②두 작성자(오퍼스·Codex)가 자막만 보고 짐작한 캡처 시각을 채점한다.

## 입력 (RUN_DIR = `<RUN_DIR>`)

- 시트 `sheets/<key>/sheet_NN.jpg` — Read 도구로 한 장씩 연다(이미지가 그대로 보인다). **모든 시트를 끝까지** 본다.
- 칸 → 시각 `sheets/<key>/index.tsv`(sheet · cell · time). 칸 번호는 왼쪽 위에서 오른쪽으로, 줄 바꿔 다시 왼쪽부터(1~24). **시각은 반드시 이 표에서 읽는다**(손으로 계산하지 말 것).
- 본보기 `answer/v1.tsv` — 형식과 판정 수준을 이것에 맞춘다.

## 판정

| label     | 뜻                                                                                                     |
| --------- | ------------------------------------------------------------------------------------------------------ |
| A         | **자료 화면** — 차트·그래프·표·도해·지도·기사·문서·슬라이드·인용 카드처럼 정보가 글자·숫자로 찍힌 화면 |
| B         | **제품·현장 장면** — 차량·로봇·공장·인물 자료 영상 등 토킹헤드가 아닌 장면                             |
| (안 적음) | 진행자·출연자가 말하는 장면(토킹헤드) · 스튜디오 · 검은 화면 · 협찬 광고                               |

- A 는 desc 에 **화면에 찍힌 제목·수치·이름을 보이는 대로** 옮긴다(반올림 금지). 읽을 수 없으면 「흐림」.
- 막대·칸이 아직 다 안 찬 **차오르는 중**이면 desc 끝에 「(차오르는 중)」을 붙이고, 같은 화면이 완성된 칸이 있으면 그 칸도 따로 적는다.
- 자막 띠(화면 아래 흰 글자)에만 있는 숫자는 A 가 아니다 — 도해 안에 있어야 A.
- 화면 일부에 진행자 패널이 붙어 있어도 나머지에 자료가 크게 떠 있으면 A.
- 협찬·광고 화면(ETF 배너 등)은 적지 않는다.

## 출력

- `answer/<key>.tsv` — 머리줄 `time\tlabel\tdesc`, 시각 오름차순, UTF-8. 맡은 key 마다 한 파일.
- 최종 메시지: key 마다 「A 몇 칸 · B 몇 칸 · 판독이 어려웠던 점」 한두 줄. 정답지 내용은 붙이지 않는다.
- 다른 파일은 만들거나 고치지 않는다.
