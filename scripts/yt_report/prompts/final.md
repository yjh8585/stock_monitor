## 할 일

1. **장면 고르기**: 정답지의 A 장면(같은 화면이 이어지는 칸 묶음)마다 본문에서 그 내용을 다루는 문단을 찾는다.
   - 본문에 이미 그 자리의 토큰이 있으면 그 토큰을 그 장면에 짝짓는다(시각이 빗나갔어도 slug 는 살린다).
   - 본문이 그 내용을 다루는데 토큰이 없으면 **새 토큰을 그 문단 바로 뒤 빈 줄에** 넣는다(slug = `<영상key>_영문이름`, 합본은 영상마다 다른 `<영상key>_` 머리로 영상을 가른다). 정답지에 있는 차트가 본문에 빠지는 것이 「차트 누락」이다.
   - 같은 슬라이드가 수십 칸 이어지면 한 장면이다 — 그림 한 장이면 된다. 내용이 바뀐 슬라이드(다음 장)는 다른 장면이다.
   - B 장면은 본문 이해에 도움이 될 때만(제품 실물·시연 장면 등) 쓴다. 인물 얼굴·스튜디오는 쓰지 않는다. 협찬 광고(ETF 배너 등)는 절대 쓰지 않는다.
2. **짝 없는 토큰은 지운다**: 정답지 ±60초 안에 대응하는 A·B 장면이 없는 토큰은 본문에서 줄째 지운다(§2-B-2 드롭이 정답 — 비슷한 화면으로 대체하지 않는다). 지운 slug 와 이유를 메모에 남긴다.
3. **시각 정하기 + 눈으로 보기**: 장면마다 시각을 정하고 미리보기를 떠서 **직접 본다**.
   ```
   YT_RUN_DIR=<RUN_DIR> python -X utf8 scripts/yt_report/grab.py <영상key> <slug> <M:SS 또는 H:MM:SS> --after 0,3,6
   ```
   → `preview/<영상key>/<slug>.jpg`(0·3·6초 뒤를 가로로 붙인 것)를 Read 로 연다.
   - **가장 늦게 완성된 판**을 고른다(§2-A — 막대·칸·글자가 다 찬 것). 장면 칸 묶음의 첫 칸보다 **가운데~끝 칸**이 안전하다. 전환 중(페이드·줌)·흐림이면 시각을 옮겨 다시 뜬다.
   - 최종 시각은 미리보기 세 장 중 고른 것의 절대 시각(기준+오프셋)으로 적는다.
4. **캡션 쓰기 — 화면에 실제로 찍힌 것만**(§2-B 3단 판정): 고른 프레임을 보고
   ① 캡션의 고유명사·수치가 **그림에 있나** ② **자릿수까지 같나**(반올림 금지) ③ **표기가 같나**. 하나라도 어긋나면 캡션을 그림에 맞춰 낮춘다. 자막 띠(화면 아래 자막)에만 있는 숫자는 그림에 있는 것이 아니다.
   - 형식: `<무엇을 보여 주는 화면인지 한 문장> (출처: <채널명>)` — 채널명은 `videos.json` 의 channel 을 그대로.
   - 그림 글자가 본문의 고유명사 표기와 다르면(자막 오타였던 것) **본문도 화면 표기로 바로잡고** 「(자막 표기)」를 지운다(§2-G). 무엇을 바꿨는지 메모에 적는다.
5. **썸네일**: 본문 맨 앞 그림이 될 대표 장면 slug 하나를 고른다(없으면 null — 유튜브 썸네일로 대체된다).

## 출력

- `reports/<key>.md` 를 직접 고친다(토큰 추가·삭제, 화면으로 확인된 고유명사 정정). 그 밖의 문장은 고치지 않는다.
- `final/<key>.json`:
  ```json
  {
    "thumb_slug": "v4_title_slide",
    "frames": [
      {
        "slug": "v4_title_slide",
        "video": "v4",
        "timecode": "1:59",
        "alt": "짧은 대체 텍스트",
        "caption": "… (출처: …)",
        "checked": "①있나 O ②자릿수 O ③표기 O — 근거 한 줄"
      }
    ],
    "dropped": [{ "slug": "...", "reason": "±60초 안에 자료 화면 없음" }],
    "renamed": [{ "before": "자막 표기", "after": "화면 표기", "where": "본문 몇 곳" }]
  }
  ```
  `frames` 는 본문 토큰 순서대로, 본문 토큰과 1:1.
- 최종 메시지: 「그림 N장 · 새로 넣음 N · 지움 N · 화면으로 바로잡은 이름 · 걱정거리」만 한국어로 짧게.
- `preview/` 밖의 다른 파일은 만들거나 고치지 않는다.
