## 할 일

1. **장면 고르기**: 공통 §8-5(짝짓기 · 한 장면 · 차트 누락). 「장면」 = 정답지의 A 장면(B 는 아래).
   - 새 토큰 자리 = **그 문단 바로 뒤 빈 줄**(slug = `<영상key>_영문이름`, 합본은 영상마다 다른 `<영상key>_` 머리로 영상을 가른다).
   - B 장면은 본문 이해에 도움이 될 때만(제품 실물·시연 장면 등) 쓴다. 인물 얼굴·스튜디오는 쓰지 않는다. 협찬 광고(ETF 배너 등)는 절대 쓰지 않는다.
2. **짝 없는 토큰은 지운다**: 공통 §8-5(정답지 ±60초 · 이 서식에선 A·B 장면 모두 짝이 된다). 지운 slug 와 이유를 메모에 남긴다.
3. **시각 정하기 + 눈으로 보기**: 장면마다 시각을 정하고 미리보기를 떠서 **직접 본다**.
   ```
   YT_RUN_DIR=<RUN_DIR> python -X utf8 scripts/yt_report/grab.py <영상key> <slug> <M:SS 또는 H:MM:SS> --after 0,3,6
   ```
   → `preview/<영상key>/<slug>.jpg`(0·3·6초 뒤를 가로로 붙인 것)를 Read 로 연다.
   - `FAIL 못 뜬 오프셋`(exit 1)이면 미리보기를 만들지 않은 것이다(영상 끝을 넘은 칸이 있다) — 시각을 앞으로 옮기거나 `--after` 를 줄여 다시 뜬다.
   - 어느 판을 고르나 · 최종 시각 — 공통 §8-1·§8-5.
4. **캡션 쓰기 — 화면에 실제로 찍힌 것만** — 공통 §8-3(3단 판정)·§8-2(자막 띠).
   - 형식: `<무엇을 보여 주는 화면인지 한 문장> (출처: <채널명>)` — 채널명은 `videos.json` 의 channel 을 그대로.
   - 그림 글자가 본문의 고유명사 표기와 다르면(자막 오타였던 것) **본문도 화면 표기로 바로잡고** 「(자막 표기)」를 지운다(§2-G). 무엇을 바꿨는지 메모에 적는다.
   - 그림의 가정 표기(`HYPOTHETICAL`·`추정`·`전망`·`예시` · 공통 §8-3)는 **캡션에만** 옮긴다. 본문에도 옮겨야 할 것 같으면 본문은 고치지 말고 최종 메시지 「걱정거리」에 적어 메인에게 넘긴다.
5. **썸네일**: 본문 맨 앞 그림이 될 대표 장면 slug 하나를 고른다(없으면 null — 유튜브 썸네일로 대체된다).

## 출력

- `reports/<key>.md` 를 직접 고친다(토큰 추가·삭제, 화면으로 확인된 고유명사 정정). 그 밖의 문장은 고치지 않는다.
- `final/<key>.json`:
  ```json
  {
    "thumb_slug": "v4_title_slide",
    "frames": [
      {
        "slug": "v4_title_slide",
        "video": "v4",
        "timecode": "1:59",
        "alt": "짧은 대체 텍스트",
        "caption": "… (출처: …)",
        "checked": "①있나 O ②자릿수 O ③표기 O — 근거 한 줄"
      }
    ],
    "dropped": [{ "slug": "...", "reason": "±60초 안에 자료 화면 없음" }],
    "renamed": [{ "before": "자막 표기", "after": "화면 표기", "where": "본문 몇 곳" }]
  }
  ```
  `frames` 는 본문 토큰 순서대로, 본문 토큰과 1:1.
- 최종 메시지: 「그림 N장 · 새로 넣음 N · 지움 N · 화면으로 바로잡은 이름 · 걱정거리」만 한국어로 짧게.
- `preview/` 밖의 다른 파일은 만들거나 고치지 않는다.
