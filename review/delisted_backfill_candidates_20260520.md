## 사용 흐름

1. 이 문서의 표를 보고 **복원 ticker 리스트** 결정 (예: 상위 46개 일괄 + 하위 22개 검토 후 추가)
2. `scripts/_delisted_restore.json` 작성:
   ```json
   {
     "tickers": ["290380", "091090", "070080", "..."],
     "reason": "DART 매칭 실패로 잘못 분류된 회사 복원 (2026-05-20)"
   }
   ```
3. `python scripts/backfill_delisted_to_active.py --dry-run` 으로 적용 계획 확인
4. `python scripts/backfill_delisted_to_active.py` 실제 적용

## 주의

- ticker가 한글 회사명 형태인 행이 다수 (예: `일진복합소재`, `한국파워트레인`) — DART 매칭 시 실제 증권 코드가 없는 비상장사이거나 코드 미부여 상태. 복원해도 다음 cron이 DART 코드를 못 찾으면 다시 `dart_collection_status='no_match'`로 marking됨 (단, status는 active 유지 — 이게 C4 작업의 핵심).
