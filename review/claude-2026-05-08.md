   - `select * from pg_policies where schemaname='public'` 실행

2. **🔴 P0 — Table·Row 컴포넌트 공통화** (`B`)
   - `components/common/BaseStockTable.tsx`, `BaseStockRow.tsx` 추출
   - 셀 헬퍼: `RevenueCells`, `OpMarginCells`, `CagrCell` 등
   - **이유**: ~600줄 중복. 글로벌·중국 페이지 추가 시 또 복사하면 유지보수 폭발.

3. **🔴 P0 — `formatRateLabel` 중복 제거** (`B`)
   - `lib/exchangeRates.ts` 신규 또는 `lib/format.ts`에 추가
   - 두 FilterBar에서 import
   - **이유**: 단순한 한 줄 정리지만 향후 통화 추가 시 빠뜨림 방지.

4. **🟡 P1 — `error.tsx`/`loading.tsx` 추가 + viewErr throw** (`C`/`H`)

   - `app/domestic/error.tsx`, `loading.tsx`

5. **🟡 P1 — `/api/news/search` 보안·로깅 보강** (`I`/`H`)
   - Zod 입력 검증 (q max 100, country enum)

   - **이유**: 외부 fetch + 무제한 호출 + ToS 위반 가능성.

## 4. 카테고리 외 발견 사항

- **데이터 신뢰성**: `resolveLatestYear`가 `['2026','2025','2024','2023']`로 하드코딩. 2027년 데이터가 들어와도 표시 안 됨. → 코드 수정 필요한 시점이 있음.
- **`POPUP_OPTS`**: `width=1400,height=900`은 현대 브라우저의 popup blocker에 막힐 수 있음. 사용자가 popup 허용 안 했으면 무반응. fallback 안내 필요.
- **`groupBadgeStyle` 해시 팔레트** (DomesticRow.tsx:32-51): 좋은 패턴이지만 그룹 추가 시 같은 색이 두 그룹에 배정될 가능성. 충돌 시 재해시 또는 수동 mapping table 검토.
- **company_type 인라인 색상 분기** (StockRow.tsx:112-118): OEM/부품사만 처리. 제3 분류 추가 시 fallback 색상 추가 필요.
- **`window.open` 직접 호출**: SPA에서 외부 새 창 띄우는 패턴. 권장은 `<a href target="_blank" rel="noopener">`. SEO·접근성·사용자 설정(새 탭 vs 새 창) 측면에서 anchor가 더 적절.
- **next/image 회피**: `CustomerBadges`에서 `eslint-disable`로 우회. SimpleIcons CDN을 `next.config.ts`의 `images.remotePatterns`에 등록하면 됨.
- **차트 미사용 페이지**: 두 페이지 자체엔 차트 없음. `lightweight-charts`/`recharts` 의존성은 stock-popup에서만 사용되는 듯. 번들 분리 확인 필요.
- **테스트 파일 부재**: 두 페이지에 대한 단위·통합 테스트 없음. `getSortValue`·`buildColumns`·`resolveLatestYear`은 순수 함수라 테스트 적합. `formatRateLabel`도 동일.
